History Simplifie — phone-ready PWA

This package is a Progressive Web App version. It can be installed on Android like an app
and can later be packaged into an Android APK/AAB using PWABuilder.

Important:
1. The files must be hosted at a public HTTPS URL before an APK can be packaged.
2. The current content-management is local prototype storage; a real student/admin system
   needs an online database and authentication (Firebase can be connected next).
3. Never share admin credentials with students.
